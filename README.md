### 2. 로컬 컴퓨터(내 PC)에서 직접 열기

#### 방법 A: 가장 간단한 방법 (브라우저로 바로 열기)
1. 저장소를 다운로드(Clone 또는 ZIP 다운로드)합니다.
2. 폴더 내의 `index.html` 파일을 더블 클릭하여 크롬(Chrome)이나 엣지(Edge) 등의 웹 브라우저로 엽니다.

#### 방법 B: 로컬 웹 서버로 구동하기 (권장)
*외부 폰트 로딩 및 링크 작동을 실제 웹 환경과 완벽히 동일하게 테스트하려면 로컬 서버를 사용하는 것이 좋습니다.*

**VS Code를 사용할 경우:**
1. VS Code에서 해당 폴더를 엽니다.
2. 확장(Extensions) 탭에서 **Live Server**를 설치합니다.
3. `index.html` 파일을 우클릭한 후 **[Open with Live Server]**를 클릭합니다 (기본 포트 `http://127.0.0.1:5500`).

**Python 터미널을 사용할 경우:**
```bash
# 저장소 루트 폴더로 이동
cd BANG-JEONGHO.github.io

# 파이썬 내장 HTTP 서버 실행 (Python 3.x)
python -m http.server 8000
